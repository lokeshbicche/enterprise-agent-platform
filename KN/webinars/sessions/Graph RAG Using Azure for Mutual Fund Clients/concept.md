About this webinar
Traditional RAG systems retrieve information from documents, but mutual fund applications often require understanding relationships between schemes, fund managers, portfolios, sectors, holdings, and investment risks. Graph RAG combines knowledge graphs with Retrieval-Augmented Generation (RAG) to enable more contextual and relationship-aware AI responses.

Join us at Krish Naik Academy for a practical session on building a Graph RAG solution using Microsoft Azure for mutual fund clients.

Key Learning Objectives

Graph RAG Fundamentals: Understand how knowledge graphs and RAG work together.

Knowledge Graph Construction: Model relationships between mutual funds, fund managers, holdings, and sectors.

Azure Architecture: Explore Azure services for building Graph RAG applications.

Data Ingestion: Process financial documents and structured data into connected knowledge.

Graph-Based Retrieval: Retrieve relevant entities and relationships to answer complex questions.

LLM Integration: Generate contextual responses grounded in retrieved financial information.

Security & Governance: Understand data access, privacy, traceability, and responsible AI.

Production Deployment: Explore evaluation, monitoring, scalability, and reliability.

WHO SHOULD ATTEND?

AI Engineers, GenAI Developers, Data Scientists, Azure Cloud Engineers, Forward Deployed Engineers (FDEs), Solution Architects, and professionals building enterprise AI applications.
