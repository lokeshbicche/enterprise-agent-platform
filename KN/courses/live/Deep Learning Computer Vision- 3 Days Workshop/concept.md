Start Date: 5th October 2024 2pm IST

Mentors: Krish Naik And Monal Singh

Dive into the world of deep learning and computer vision in this immersive 3-day workshop designed for beginners and intermediate learners. Whether you're looking to enhance your skills in image processing, neural networks, or real-time object detection, this workshop will provide hands-on experience with some of the most powerful tools in AI today, such as OpenCV and YOLO.

Participants will explore the full spectrum of computer vision techniques, from basic image processing to advanced object detection. By the end of the workshop, you’ll have a solid foundation in deep learning for computer vision and practical skills to implement these techniques in real-world scenarios.

Workshop Agenda:

Day 1: Image Processing & Computer Vision with OpenCV

Introduction to computer vision and its applications.

Fundamentals of image processing using OpenCV.

Key image transformations, filters, and feature extraction techniques.

Hands-on practice with basic image operations (blurring, edge detection, etc.).

Day 2: Image Classification and Convolutional Neural Networks (CNN)

Image Classification with Neural Networks: Learn how neural networks can classify images.

Need for CNN: Understand the limitations of traditional neural networks in image processing and why CNNs are essential.

Image Classification with CNN: Dive deep into the architecture and working principles of Convolutional Neural Networks.

Evaluating CNN Performance: Learn to fine-tune and evaluate the performance of CNN models using common metrics and techniques.

Day 3: Object Detection with YOLO

Understanding the Need for Object Detection: Learn the importance of object detection in various industries and use cases.

History of Object Detection: A brief overview of the evolution of object detection techniques.

Real-Time Object Detection with YOLO (You Only Look Once): Implement and work with the powerful YOLO algorithm for real-time object detection, gaining hands-on experience with its capabilities and applications.
